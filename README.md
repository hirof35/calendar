📅 予定一覧付きスケジュール帳 (GUI Calendar Planner)
Pythonの tkinter と tkcalendar を使用した、視覚的で直感的なスケジュール管理アプリケーションです。

🌟 概要
カレンダー上での日付選択と、全予定のリスト表示を同期させた、実用性の高いデスクトップツールです。予定の追加、時間順の自動ソート、一括管理（閲覧・削除）が可能で、データはJSON形式で自動保存されるため、長期的なタスク管理に適しています。

✨ 特徴機能
カレンダー・マーキング:

tkcalendar を採用。予定が入っている日を「スカイブルー」でハイライト表示し、一目で活動日が分かります。

時系列自動ソート:

同一日の予定は、入力順ではなく「時間順」に自動で並び替え。効率的なスケジュール確認をサポートします。

フル・データ永続化:

JSON 形式でデータを保存。日本語文字化けを防ぐ ensure_ascii=False 設定や、読みやすいインデント出力を実装。

直感的な一覧管理:

下部の Listbox で過去から未来までの全予定をスクロール確認。選択した項目のクイック削除にも対応。

日本語ローカライズ:

カレンダーの表示言語や日付パターンを日本国内の標準（yyyy-mm-dd）に適合。

🛠 技術スタック
GUI Framework: tkinter

Calendar UI: tkcalendar

Data Storage: json (ファイルベースDB)

Logic: Python標準ライブラリ（os, datetime）

🚀 クイックスタート
1. 依存ライブラリのインストール
Bash
pip install tkcalendar plyer
2. アプリの起動
Bash
python schedule_app.py
🕹 使い方
日付の選択: カレンダーから予定を入れたい日をクリックします。

情報の入力: 「時間」と「内容」を入力し、「予定を追加」ボタンを押します。

予定の確認:

カレンダー上で色が着いた日を確認。

下部の一覧リストで全スケジュールを俯瞰。

予定の削除: リストから不要になった項目を選択し、「選択した予定を削除」ボタンを押します。

📂 データ構造設計
schedule_full_data.json には以下の構造で効率的にデータが格納されます：

JSON
{
    "2026-04-27": [
        { "time": "12:00", "task": "ランチミーティング" },
        { "time": "15:00", "task": "システム設計レビュー" }
    ]
}
